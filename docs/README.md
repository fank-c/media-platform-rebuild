# 项目功能文档

先看 [项目模块开发 TODO](TODO.md) 了解功能进度，再按业务模块查使用方式、处理流程和限制。同一模块的接口、数据变化和关键分支放在同一篇文档中，不再拆成多套分类。

调用接口时查看 [HTTP 接口文档](api.md)：集中列出请求参数、返回字段、权限和关键错误；处理过程仍以对应模块说明为准。

## 如何理解进度

- TODO 的勾选仅表示当前工作区代码已实现该条所述范围，不表示已启用、测试通过或真实环境可用。
- 模块文档按与 TODO 对应的 Part 解释行为；默认配置以仓库文件为依据，不代表 Nacos 或运行环境的实际值。
- 每篇末尾分别记录应验证的内容与本次实际检查。测试源码是验证入口，不是通过记录。
- 本次整理基于 2026-09-09 的工作区，包含尚未提交的文件服务变更。旧文档的阶段确认不直接作为当前版本验收结论。

已有的[文件模块问题记录](file-issues.md)保留在原位置，作为历史问题和后续核查线索；当前功能行为以文件模块文档及源码为准，不另外创建重复问题清单。
