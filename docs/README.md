## 内容状态与事实来源

- **当前实现**：已在工作区代码、SQL 或配置中定位；不能等同于测试通过或生产可用。
- **历史报告**：前次执行者记录的结果；缺少本次复现时必须保留时间与验证限制。
- **目标设计**：约束或后续方向，不应提供假定已存在的接口、脚本或基础设施操作。
- **待验收**：必须补充测试、运行环境或独立审查证据后才能关闭。

行为核对以源码、配置和 SQL 为证据；契约是兼容性约束，不能因代码有偏差就静默改写。
若实现与契约冲突，应记录差异并走审查流程。本次整理补录遗漏接口，不改变代码、鉴权或路由。

## 如何维护

1. 每个事实只在一个主文档详细说明，其他文档用链接引用。字段维护在契约，建表定义维护在 SQL。
2. 新增 API、配置、所有权或服务职责时，同步修改对应主文档；重大架构变化新增 ADR。
3. 方案中的实现思路、测试步骤、阶段结果分别融入领域设计、测试指南和迁移状态，
   不继续在任务目录复制整份 Java/YAML/SQL。
4. `tasks/` 中既有路径仅作兼容入口，不新增独立工作记录目录。新的功能点设计放在对应主题文档。
5. 功能进度统一维护在 [TODO](TODO.md)，按模块维护当前设计的功能任务和必要的实现记录；详细方案、验证和回退仍写回主题文档，不新增独立工作记录目录。
6. 已接受 ADR 不改写历史结论；协作规则仍以 [AGENTS.md](../AGENTS.md) 为准。
