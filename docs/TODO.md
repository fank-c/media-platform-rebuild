## 2. 网关模块

### gateway-service

当前进度：以下功能已有代码或路由配置，待核验。
依据：[认证设计](reference/authentication.md)、[网关源码与配置](../service/gateway-service/src/main)。

- [ ] 统一路由：将认证、用户、内容、审核、互动和推荐请求转发到对应服务。
- [ ] 匿名接口放行：按配置的白名单允许无需登录的请求进入下游。
- [ ] 请求认证：提取 Bearer Token，调用认证服务验证，拦截缺失或无效身份。

- [ ] 注销缓存清理：经网关注销时尝试清理当前 Token 的认证缓存。

边界：注销缓存清理仍存在失败与并发窗口；已有路由不表示对应下游业务已经实现。

## 3. 认证模块

### auth-service

当前进度：第一阶段功能已由用户确认收尾；以下实现已静态核对，独立运行验收按测试指南保留边界。
依据：[认证 HTTP v1](contracts/http/auth-api-v1.md)、[账号创建事件](contracts/events/auth.account.created.v1.md)、
[认证应用层](../service/auth-service/src/main/java/com/calles/platform/auth/application)。

- [ ] 账号注册：创建普通认证账号，保存密码哈希，不自动登录、不直接写用户资料表。
- [ ] 账号登录：校验登录名、密码与账号状态，签发访问令牌和刷新凭据。
- [ ] 令牌刷新：Redis begin 消费旧凭据并保留轮换标记，校验账号后条件 finish；logout 删除会话后不能重建，失败按本次标记清理。
- [ ] 退出登录：删除当前刷新会话，将当前访问令牌加入撤销记录。
- [ ] 令牌验证：向网关提供 Token 有效性及认证主体信息。
- [ ] 当前账号查询：返回当前认证账号摘要，不承载用户资料编辑。
- [ ] 账号创建事件登记：注册事务内同时写入账号与 Outbox 待投递记录。
- [ ] 账号创建事件发布：通过 RabbitMQ 发布事件，处理发布确认、领取租约、有限重试和失败状态；提交后快速触发默认关闭，与扫描共用条件领取，积压统计独立调度。
- [ ] 已有认证账号的资料事件补齐：为新认证库中的已有账号补充初始化资料事件，支持 dry-run、分批处理与进度记录。

边界：资料事件补齐不是旧单体账号迁移；当前令牌验证不承诺账号禁用或角色变更即时生效。

## 4. 用户模块

### user-service

当前进度：第一阶段功能已由用户确认收尾；以下实现已静态核对，独立运行验收按测试指南保留边界。
依据：[用户 HTTP v1](contracts/http/user-api-v1.md)、[账号创建事件](contracts/events/auth.account.created.v1.md)、
[用户源码](../service/user-service/src/main/java)。

- [ ] 本人资料查询：返回当前用户资料；资料尚未创建时返回 `PENDING`，不因查询写入数据库。
- [ ] 本人资料编辑：修改昵称、简介、城市和生日，支持缺失资料首次保存与显式清空字段。
- [ ] 资料并发更新控制：使用 `revision` 防止旧版本覆盖新修改，冲突返回 409。
- [ ] 公开资料查询：返回允许展示的资料字段，对不存在、停用和删除资料统一隐藏。
- [ ] 批量资料摘要查询：批量返回账号摘要，保留请求顺序和重复项，标记不可用资料。
- [ ] 管理端资料列表：按账号、昵称前缀和状态筛选，支持分页查询。
- [ ] 管理端资料编辑：允许管理员编辑已有且正常的资料，沿用版本控制，不提供启停或恢复能力。
- [ ] 可信头像展示：按配置的可信前缀约束头像展示，不开放资料 PATCH 修改头像。
- [ ] 账号创建事件消费：解析并校验事件，将协议数据转换为服务本地输入。
- [ ] 用户资料异步初始化：按账号创建事件建立缺失资料，幂等登记与资料初始化同事务执行，不覆盖已有资料。
- [ ] 消费失败处理：临时失败有限重试，非法事件与重试耗尽消息进入死信队列。

边界：资料状态不替代认证状态；关注关系不属于本模块当前资料功能。
