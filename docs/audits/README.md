# 问题审计记录

本目录记录当前分支已经发现的问题、证据、影响、修复记录和剩余风险。它不是实时待办看板；当前要做什么以 [`../TODO.md`](../TODO.md) 为准，当前实现以 [`../modules/`](../modules/) 和 [`../api.md`](../api.md) 为准。

| 文档 | 范围 |
| :--- | :--- |
| [`interaction-audit.md`](interaction-audit.md) | 互动服务问题、历史修复和剩余环境验收 |
| [`recommend-audit.md`](recommend-audit.md) | 推荐服务问题、跨服务契约风险和规划缺口 |

审计文档可以保留已解决问题，便于解释为什么当前代码与旧实现不同。新增问题时应记录核对基线、代码证据、影响、状态和验收条件；完成修复后更新审计记录，并在 `TODO.md` 保留必要的未完成动作。
